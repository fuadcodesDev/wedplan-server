
# WedPlan Server

Backend API for WedPlan — a Wedding Planning Platform.

## Technologies
- Node.js
- Express.js
- TypeScript
- MongoDB
- CORS
- dotenv

## Features
- Express API server
- TypeScript configuration
- Health check endpoint
- Environment variable support
- MongoDB integration (upcoming)

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Environment Variables

Create a `.env` file in the project root.

Never commit your actual environment secrets.

## API Health Check

```text
GET /api/health
```

Development URL:

```text
http://localhost:5001/api/health
```
